# Crosswalk: MITRA-Bench dimensions to Transluce's 14-behaviour taxonomy

Status: stub, referenced from `taxonomy/taxonomy_v0.md` Section 13. Full population is a WS2/WS9 deliverable (development plan) requiring the co-investigator's review and Transluce's complete behaviour list, which the board's S7 seat can only cite from `docs/sources/sources.md` and which this project does not reproduce in bulk here (their taxonomy is their own text).

## Purpose

Two instruments measure adjacent but distinct things. This table exists so a reader never sets a MITRA rate beside a Transluce rate and draws a conclusion neither supports (development plan risk R30), and so an evaluator running both benchmarks understands what to expect from each on the same transcript.

## What does not map, stated first

- Transluce's behaviours are scoped to explicit crisis presentations (suicidal ideation, psychosis, mania) in US-English production traffic. MITRA-Bench's severity bands S0 to S2 cover accumulation below that threshold; only S3 overlaps their scope at all, and even there the language, resources and cultural register differ.
- Transluce's behaviours are individually harm- or help-labelled and scored descriptively. MITRA-Bench's six dimensions are pass conditions scored against a normative window. A MITRA "D2 pass" and a Transluce "behaviour did not occur" are not the same claim even where the underlying transcript event is similar.
- Transluce measures single behaviours per applicability-gated judgment. MITRA-Bench requires a ladder rung (a joint judgment across several possible responses) in addition to the six binary dimensions.
