## Rules

- A claim not in this table is not citable by the board until a row is added with a locator and a date.
- Numbers in this table are the numbers the package uses. If a document states a different figure, the document is wrong or the table needs a new dated row, never both silently.
- Re-verify any row older than ninety days before a submission-grade artifact ships.
